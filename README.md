# Automated WAV -> MP3 -> DAP Python Script
Automated Python script that converts properly ID3 tagged wav files into mp3 and moves them to my DAP.

**NOTE**
Please rememeber to have the WAV files tagged with correct ID3 info before running the script.
This ensures that the renaming of the files performed in this scripts happens correctly.

### Dependencies
- You need to have `ffmpeg` and `exiftool` installed on your computer, and they need to be in the path.
- The Python script only uses standard packages.
- **NOTE**: the script is only tested on MacOS.
